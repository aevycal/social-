aveysocial - setup
1. Supabase Dashboard > SQL Editor: paste schema.sql and run it (safe to re-run after updates).
2. (Testing) Authentication > Providers > Email: turn off "Confirm email".
3. Keep index.html, style.css and app.js in the same folder, then open index.html
   or upload the folder to Netlify, Vercel or GitHub Pages.
